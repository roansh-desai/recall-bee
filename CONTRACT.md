# Shared implementation contract
Source of truth: shared/types.ts and shared/schema.sql. Do not change these without coordinating with root.
Root owns server/db.ts, server/index.ts, package.json and integration. Ingestion owns server/bee.ts, server/ingest.ts, server/normalize.ts and probes. Extraction owns server/extract.ts and fixtures/conversations.json. Brief agent work grouped with extraction: server/brief.ts, server/ask.ts, server/todos.ts. UI owns src/*, index.html and vite.config.ts. Docs supplied by ingestion and root.
Pure extraction API: extractConversation(conversation: Conversation, existingPeople: Person[]): ExtractionResult. Source every claim, stable deterministic ids within conversation, never cross-conversation auto merge.
Brief API: brief(person: Person, conversations: Conversation[]): Brief.
Ask API: ask(query: string, bee: BeeClientContract, fixtureConversations?: Conversation[]): Promise<AskAnswer>.
BeeClient class implements BeeClientContract; constructor may use env. Ingest worker API: startIngest({onConversation:(c:Conversation)=>void, onStatus:(patch:Partial<LiveStatus>)=>void, isForgotten:(id:string)=>boolean}): {stop():void,sync():Promise<void>}. Normalize conversation from documented/probed shapes.
HTTP: GET /api/state -> Snapshot; GET /api/people/:id/brief -> Brief; POST /api/ask {query}->AskAnswer; POST /api/sync; PUT /api/conversations/:id/speaker {speaker:string}; PUT /api/people/:id {name}; DELETE /api/people/:id; PUT /api/promises/:id {completed:boolean}; POST /api/merges/:id {action:'merge'|'separate'}; GET /api/export -> JSON download. Poll state every 3sec. No cloud LLM.
Mode env RECALL_MODE=fixture|live; default live. Explicit fixture command must display persistent fixture badge. DB env RECALL_DB default data/private/recall.sqlite; fixture separate fixture.sqlite. Bind localhost only. Bee proxy port 8787. Server port 3210, Vite port 5173.
Privacy forget: remove all containing conversations and all derived data from those conversations, even shared-person details, and add conversation ids to forgotten_conversations to prevent backfill resurrecting them. No original payload storage outside ignored private folder. No real screenshots committed.
